# Retro handheld

`retro-handheld.glb` is generated by `scripts/create-retro-handheld.py` in Blender.
The editable scene is `scripts/retro-handheld.blend`. All original exterior mesh
names are retained; the body now has a hollow cavity beneath its back panel.

Configurable groups:
- Body: `body`, `back_panel`
- Buttons: `button_a`, `button_b`
- D-pad: `dpad`
- Screen: `screen`

Unchanged exterior details: `screen_bezel`, `start_button`, `select_button`,
`speaker`, `side_buttons`, `screws`.

Interior meshes (visible only with Translucent selected):
- `internal_pcb`: green circuit board
- `internal_battery`: rear battery pack
- `internal_chip_main`, `internal_chip_power`: two chip blocks
- `internal_speaker`: circular speaker module
- `internal_posts`: four shell support posts
- `internal_ribbon`: copper-colored connector ribbon
- `internal_traces`: simplified PCB trace details

Each internal mesh has a material named `<mesh_name>_material`. Internals fit
inside the shell. Body transmission preserves opaque alpha and uses physical
refraction, mild frosting, and reflection highlights instead of opacity fading.
Matte/Glossy hide the internals; other exterior materials remain unchanged.

`src/configuration.js` defines palettes, finishes, four scene moods, and five
product editions. Editions preserve the scene; scene changes preserve the
selected edition. Individual product edits show Custom when no edition matches.
Reset restores Classic, Studio, and the default camera.

`src/scene/environment.js` uses a procedural room reflection map and restrained
background/light presets without external HDR assets. Scene changes do not
reset OrbitControls. `src/scene/viewer.js` handles framing, resizing, and loading.

Checks: `npm test`, `npm run test:browser`, and `npm run build`.
Browser tests use the installed Google Chrome application on this Mac.

## Premium model refinement

The housing now consists of front/rear shells with a thin assembly seam and a
fitted rear battery door. The battery door is joined into `back_panel`, so its
color and finish continue following Body. Controls sit in recessed wells. The
screen assembly has an inset display, inner frame, and separate transmitting
glass. A status LED, power slider, volume wheel, headphone jack, ventilation,
and four cross-drive screws provide restrained hardware detail.

All original meshes were refined without renaming:

| Group | Modified meshes |
| --- | --- |
| Housing | `body`, `back_panel` |
| Display | `screen_bezel`, `screen` |
| Controls | `dpad`, `button_a`, `button_b`, `start_button`, `select_button`, `side_buttons` |
| Hardware | `speaker`, `screws` |
| Interior | `internal_pcb`, `internal_battery`, `internal_chip_main`, `internal_chip_power`, `internal_speaker`, `internal_posts`, `internal_ribbon`, `internal_traces` |

New meshes, each with a `<mesh_name>_material` material:

| Mesh | Purpose |
| --- | --- |
| `shell_seam` | Housing gasket / assembly reveal |
| `battery_latch` | Recessed battery-door catch |
| `display_frame` | Inner LCD surround |
| `screen_glass` | Thin reflective/transmitting display cover |
| `control_wells` | Fitted button and D-pad surrounds |
| `status_led` | Small green status indicator |
| `power_switch` | Grooved slider |
| `volume_wheel` | Scalloped side volume control |
| `accessory_port` | Headphone socket and metal rim |
| `rear_vents` | Recessed backing behind service vents |
| `screw_wells` | Rear screw counterbores |
| `internal_battery_strap` | Battery retention band |
| `internal_contacts` | Chip legs and connector contacts |
| `internal_passives` | Small board-mounted electronic components |

All 11 `internal_*` meshes remain hidden outside Translucent mode. The battery
is behind the PCB, the speaker sits behind the front grille, and hollow support
posts align with the service screws. No internal part protrudes from the shell.

The three finish values were tuned for this shell; the Edition/Scene rules,
UI, color groups, and camera behavior remain unchanged. Every mesh has one
material slot. There are no image textures or subdivision-heavy components.

Exact mesh/material inventory, geometry count, and byte size are in
`scripts/retro-handheld-validation.json`, regenerated by
`node scripts/validate-retro-handheld.js`.

## Real environments and final polish

`src/scene/environments.js` builds four procedural sets, each in its own named
Three.js group, with a dedicated lighting rig and fog configuration:

- Studio: curved cyclorama, neutral floor, softbox geometry, soft contact shadow.
- Retro Desk: wood-grain desktop, instanced keyboard keys, cassette, notebook,
  and a small warm desk lamp.
- Arcade: two original cabinets, simple illuminated screens and blank marquees,
  floor inlays and colored light bars. No branding or licensed imagery.
- Dark Tech: graphite plinth, metallic floor, structural panels and linear lights.

Groups are created once on demand, with exactly one visible at a time, including
its lights. All four groups are reused on repeated switches and disposed on
viewer teardown. Product coordinates and camera position are unaffected.
`environment-validation.json` reports the geometry budgets; browser tests check
stable group UUIDs, child counts, GPU geometry/texture counts, and product state.

The final handheld adds `internal_capacitors`, `internal_solder`, and
`internal_battery_connector`, retaining all previous mesh names. The PCB now
has assembly clearances. The side slider, wheel and accessory socket sit deeper
in the housing. Shell edge radii and the gasket are restrained; the frosted
finish uses transmission with lower coat/specular response and more roughness,
not opacity fading. All 14 internal meshes use the existing visibility behavior.

The LCD has explicit UVs and a small neutral pixel-grid DataTexture from
`src/scene/screen-surface.js`. It multiplies the chosen screen color, fades with
mipmapping at normal distances, and has a restrained color-following emission.
The separate glass layer remains above the slightly inset LCD.

Final model and environment budgets are regenerated using
`node scripts/validate-retro-handheld.js` and reported in the JSON files under
`scripts/`. Chrome tests include screenshots for all four sets, repeated scene
switching, all product controls, material changes, and Reset.


### Final polish

Updated GLB: **35,378 triangles, 1,064,516 bytes**, preserving all 37 mesh names.
Sharper shell transitions, shallow dished buttons, recessed slider housing,
acoustic backing ribs and PCB vias are generated by the existing Blender script.
Closed-solid materials export single-sided. The shell's runtime transmission
thickness is now 2.5 mm in asset coordinates, correcting the previous 35 mm
refraction displacement; FrontSide rendering removes the redundant back-face
transmission pass. Opacity stays 1 and depth writing stays enabled.
See `scripts/environment-art-direction.md` for the final visual and test report.
