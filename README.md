# Retro Handheld Configurator

An experimental 3D retro handheld configurator built with Vite and Three.js.

Users can customise the handheld, explore it in different 3D environments and enter Play Mode to play retro-inspired mini-games.

## Features

- Interactive 3D handheld
- Rotate and zoom controls
- Body colour customisation
- Button colour customisation
- D-pad customisation
- Screen customisation
- Matte, Glossy and Translucent materials
- Visible internal electronics
- Edition presets
- Four 3D environments
- Animated Arcade environment
- Play Mode
- Vector Field mini-game
- Space Invaders-inspired mini-game
- Responsive desktop and mobile layout

## Scenes

- Arcade
- Studio
- Retro Desk
- Dark Tech

Arcade is currently the default scene.

## Technology

- Vite
- JavaScript
- Three.js
- GLTF / GLB
- Vitest
- Playwright
