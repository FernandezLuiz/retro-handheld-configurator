# Retro Handheld Configurator

An experimental 3D retro handheld configurator built with Vite and Three.js.

Users can customise the handheld, explore different 3D environments and enter Play Mode to play retro-inspired mini-games.

## Live project

https://retro-handheld-configurator.vercel.app

## GitHub

https://github.com/FernandezLuiz/retro-handheld-configurator

## Features

- Interactive 3D handheld
- Rotate and zoom
- Customisable body, buttons, D-pad and screen
- Matte, Glossy and Translucent materials
- Visible internal electronics
- Edition presets
- Four 3D environments
- Animated Arcade environment
- Play Mode
- Vector Field
- Space Invaders-inspired game
- Responsive desktop and mobile layout

## Scenes

- Arcade
- Studio
- Retro Desk
- Dark Tech

Arcade is the default scene.
