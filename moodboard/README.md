## Colour direction

The interface uses a warm neutral base with playful retro-tech accents.

Cream and dark Ink create the main visual structure and keep the interface calm enough for the 3D product to remain the main focus.

Acid Lime is reserved for important interactive moments and should not be used everywhere.

Burgundy, Sage, Clay and Mint add personality through product editions, buttons and secondary interface elements.

The palette should feel playful and nostalgic without becoming a direct recreation of an existing retro console.

---

# Typography

## Display typeface

**Syne ExtraBold**

Used for:
- main titles
- large GAMEBOY title
- graphic statements
- important visual moments

The display typography should feel oversized, playful and experimental.

Typography can act as a graphic element in the composition rather than only as readable text.

Large text can intentionally interact with the 3D product and surrounding layout.

---

## Body / UI typeface

**IBM Plex Sans**

Used for:
- navigation
- labels
- configurator controls
- descriptions
- instructions
- small interface text

The body typography should remain simple, technical and highly readable.

It creates a visual contrast with the more expressive display typography.

---

## Typography hierarchy

The interface follows this hierarchy:

1. Main 3D / display title
2. Secondary headlines
3. Configurator section titles
4. Body copy and control labels
5. Technical microcopy and status information

Microcopy should remain visually secondary and should never compete with the product or main interface actions.

---

# Shape & spacing

The interface combines sharp, graphic interface elements with softly rounded product geometry.

The web interface should not rely heavily on generic rounded cards or pill-shaped buttons.

Controls can feel playful and experimental, but their alignment should remain deliberate.

The layout uses generous whitespace and a clear underlying grid.

Spacing is based on an 8px system:

`8 / 16 / 24 / 32 / 48 / 64px`

The composition may be asymmetric, but elements should still align to clear visual axes.

The left 3D viewer can be more expressive, while the configurator controls should maintain a stronger and more predictable structure.

Avoid:
- random spacing
- excessive rounded cards
- generic SaaS-style interface components
- unnecessary decorative elements

---

# Materials

The handheld uses three main material directions:

- Matte plastic
- Glossy plastic
- Translucent plastic

The materials should feel tactile and product-like rather than overly realistic or metallic.

Matte materials should have soft and restrained reflections.

Glossy materials may have stronger highlights without becoming mirror-like.

Translucent materials should reveal the internal electronics while keeping the outer shell and silhouette readable.

Visible internal components are part of the visual identity of the translucent edition.

---

# Lighting

## Studio

The default Studio scene uses soft and controlled product lighting.

The lighting should:
- clearly reveal the form of the handheld
- create soft shadows
- avoid overly harsh highlights
- separate the handheld from the background
- keep colours and materials easy to inspect

## Retro Desk

The Retro Desk scene uses warmer and more atmospheric lighting.

The goal is to create a comfortable nostalgic workspace with warm wood and soft practical lighting.

## Arcade

The Arcade scene uses stronger atmospheric lighting with cyan, purple and pink accents.

Glowing screens and neon lighting can create more contrast than in the Studio environment.

## Dark Tech

The Dark Tech environment should feel darker, more technical and more futuristic.

Lighting can use controlled strips and highlights to reveal the silhouette without losing the dark atmosphere.

---

# Layout direction

The design should feel playful and experimental while still having a disciplined visual hierarchy.

The 3D handheld remains the main focal point.

Large typography can be used around the product as part of the composition.

Supporting text should be grouped instead of appearing as unrelated floating elements.

Configurator controls should follow consistent left and right alignment.

Important actions such as ENTER GAME should be visually easy to identify.

The interface should remain usable and readable on desktop, narrow desktop and mobile screens.

---

# Motion & interaction

Motion should reinforce the retro-tech identity.

Possible effects include:
- short CRT flickers
- pixel transitions
- subtle glitches
- text jitter
- screen glow
- chromatic offsets
- short frame-stepping effects

These effects should mainly appear during interaction and transitions rather than constantly.

Animations should not make the interface harder to use.

Reduced-motion behaviour should remain available when possible.

---

# Overall visual direction

The final visual identity combines:

- playful retro technology
- contemporary product presentation
- oversized experimental typography
- warm neutral colours
- translucent electronics
- arcade-inspired lighting
- structured but asymmetric layouts
- restrained CRT and pixel effects

The result should feel nostalgic without becoming a direct copy of an existing console, game or brand.

The moodboard acts as a guide for individual visual qualities rather than as something to reproduce literally.
